# Publish to GitHub Pages

This folder contains the public legal pages for **Stack Rush** (ASC: Stack Rush: Block Tower).

## Enable GitHub Pages

1. Open https://github.com/jshugart90-png/stack-rush-privacy/settings/pages
2. **Build and deployment** → Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save

Pages will be live in 1–3 minutes at:

- **Privacy Policy:** https://jshugart90-png.github.io/stack-rush-privacy/
- **Support:** https://jshugart90-png.github.io/stack-rush-privacy/support.html
